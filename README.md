# Ratio data feed
Machine-generated data for https://kurzlernen.de/ratio.html.
CapEx and demand facts come from official SEC CompanyFacts and SEC-filed disclosures. PEG uses live market data, SEC-derived calculations, and a named public market-data fallback when necessary. Loss-making firms retain a transparent signed forward PEG but are marked pegMeaningful=false.
No synthetic/random fallback values are permitted.
Publication requires all 45 tracked companies to have complete validated inputs.
