Arondight45 S31 Hardware-in-the-Loop

  
No browser flight-controller fallback. The physical ESP32-S31 executes the production fc:: filter, attitude, arming, PID, mixer and pulse code. Box3D only integrates the simulated airframe.

  

  

  
Hard requirements
Desktop Chromium with WebSerial. Flash esp32/Arondight45_DroneFC_HIL_S31.cpp as the only component source. The adapter directly includes the production controller source. If no real board is connected, this page will not simulate a controller.
